# Changelog

Public release changes to NullKeys will be documented in this file.

## [1.0.0]

- First stable public source release.
- Adaptive practice, fixed-condition typing tests, local progress history, and keyboard-layout analysis without accounts or remote data services.
- English, Persian, and Russian product languages with nine browser-served v1 content packs.
- Validated local archive portability, benchmark integrity rules, and generated offline support.
